# «Телефон за 7,6 миллиарда» — проект Remotion

Готовая раскадровка на **128 сцен** под вашу озвучку (11:05, `public/audio/voiceover.mp3`) плюс 6-секундный финал.
Размер 1920×1080, 30 к/с, всего **20 139 кадров**.

## Запуск
Нужны Node.js 18+ и ffmpeg (для LUT).

```bash
npm install
npm start                # Remotion Studio: предпросмотр и правки
npm run test:render      # пробный рендер первых 30 секунд (out/test.mp4)
npm run render           # полный рендер + LUT -> out/final_graded.mp4
```

Если `npm install` не находит версию 4.0.250, выполните `npx remotion upgrade` или поставьте
одинаковую свежую версию для `remotion` и `@remotion/cli` (версии пакетов Remotion должны совпадать).

## Что внутри
- `src/timeline.json` — вся раскадровка: старт и конец каждой сцены в секундах, файл картинки/ролика, камера, оверлеи. Править можно прямо тут.
- `public/images/Scene_001.jpg … Scene_128.jpg` — картинки (названия по порядку монтажного листа).
- `public/clips/` — 28 ваших анимационных роликов (`Scene_NNN.mp4`) и ролик со статьёй (`article_microsoft.mp4`).
- `public/audio/voiceover.mp3` — озвучка, `public/overlays/hook_counter.srt` — SRT-счётчик, `public/grade/Doc_70s_Warm_Faded.cube` — LUT.
- `MATCH_TABLE.csv` — таблица соответствия: сцена, время, исходный файл фото/ролика, что использовано.

## Как собрана раскадровка
1. **Сопоставление.** Все 128 картинок опознаны по содержимому и привязаны к промтам (Scene_001…128). Ролики сопоставлены с картинками по первому кадру.
2. **Исключения.** Для 28 сцен есть анимационные ролики: там стоит ролик, а фото исключено. Ещё в сцене Scene_108 вместо фото стоит ролик со статьёй (Tech Journal, подсветка маркером «Microsoft's phone», «Brought down», «by a late entry»).
3. **Тайминг.** Границы шести блоков озвучки взяты из `msftphone_block_timepoints.json`. Границы сцен внутри блоков определены по вашему черновику `msftphone_full.mp4` (номера сцен и смена субтитров), дальше сцены разбиты по числу слов и притянуты к паузам речи. Точность примерно ±0,5 с, у части сцен отдельные границы могут чуть отличаться от речи: поправьте `start` в `timeline.json`.
4. **Первые 30 секунд.** Начинается 7 сцен (Scene_001–007), на первой счётчик из SRT по центру («$0.0 billion» → «$7.6 billion»).

## Эффекты
- **Камера по картинке:** `zoomIn`, `zoomOut`, `panLeft`, `panRight`, `driftUp`, `driftDown`, `refPush` (повторяет динамику референса: плавный наезд за 45% времени, затем медленное «дыхание»). Меняется полем `camera` у сцены.
- **Ролики:** подгоняются под длину сцены скоростью 0.6×…1.5×.
- **Растворение** между сценами: `dissolveFrames` (5 кадров).
- **Счётчики** (`overlays` → `counter`): числа из монтажного листа (12 %, $500 млн, 200 000+, 48 дней, €5,44 млрд, 7 800 человек и т.д.).
- **Подсветка слов маркером** (`keyphrase`): жёлтый маркер выезжает слева направо с постоянной скоростью 0,074 с на букву.
- **Плашки** (`plaques`) в стиле шаблона канала; в финале пять главных ошибок (Outro).
- **LUT `.cube`:** Remotion не умеет применять LUT напрямую, поэтому `npm run render` после рендера накладывает его через ffmpeg (`lut3d`). В Studio цвет без LUT.
- **Зерно плёнки:** включается `"grain": true` в `timeline.json` (рендер дольше).

## Важно
- Проект написан без запуска Remotion (в среде, где я его готовил, нет доступа в интернет): код проверен только на синтаксис и типы с заглушками. Если рендер выдаст ошибку, пришлите её текст, я поправлю.
- Глобус и карта с пинами (Рочестер → Токио) в раскадровку не вставлялись: в сценарии для них нет подходящего места. Видео лежат отдельно, при желании их можно добавить сценой.
- Субтитры в проект не включены.

## Рендер без компьютера: GitHub Actions (можно управлять с телефона через Termux)
В Termux сам Remotion, скорее всего, не заработает (ему нужен Chrome под обычный Linux). Поэтому Termux нужен только, чтобы выложить проект на GitHub, а рендерит облако.
1. На github.com создайте пустой репозиторий (например, `film`).
2. В Termux: `pkg install git unzip`, затем `termux-setup-storage`.
3. `cd ~ && unzip ~/storage/downloads/msft_phone_film_remotion.zip -d film && cd film`
4. `git init && git add . && git commit -m "film" && git branch -M main`
5. `git remote add origin https://github.com/ВАШ_ЛОГИН/film.git && git push -u origin main`
   (вместо пароля вводится токен: GitHub → Settings → Developer settings → Personal access tokens, право `repo`).
6. В репозитории: вкладка **Actions**. Сначала запустите **Render test** (Run workflow), затем **Render film (полный рендер)**.
   Полный рендер идёт 4 частями параллельно, потом склеивает их, добавляет озвучку и LUT.
7. Готовый файл: открыть выполненный запуск → блок **Artifacts** → `final-film` (внутри `final_graded.mp4`).
